# G2B Schoolspelen 🎓

Speels leren voor kinderen (en doorzetters): **rekenen en lezen** —
van basisschool tot genius. Gratis, lokaal, 100% commercieel (regel 1).

## Wat het is

Eén webpagina (`index.html`) die overal werkt: pc, tablet, telefoon.
Geen installatie, geen account, geen internet nodig na het laden.

- **Niveau-ladder**: Groep 1–2 → Groep 3–4 → Groep 5–6 → Groep 7–8 →
  Middelbaar 1–5 → Universiteit → Master 1-2-3 → Genius 🏆
- **Vakken**: Tellen · Letters · Plus · Min · Tafels · Procenten ·
  Breuken · Woorden · Spelling · Zin lezen · Begrijpend lezen · Logica
- **Adaptief brein**: de app onthoudt fouten (per apparaat,
  localStorage). Woorden en sommen die lastig zijn komen vaker terug,
  met een truc-tip erbij. Te makkelijk? Kies een hoger niveau.
- **🔊 Nederlandse stem**: de app leest voor (dictee, letters,
  mee-tellen) via de ingebouwde browser-stem — gratis, werkt meteen.
- **⭐ Motivatie**: sterren verzamelen, voortgangsbalkjes per vak,
  medaillescherm na elke ronde van 8.

## Zo gebruik je hem

Open `index.html` in je browser — dat is alles. Of publiceer hem op
GitHub Pages en deel de link met iedereen.

Lokaal serveren (optioneel):

```
python -m http.server 8099
# open http://localhost:8099/index.html
```

## Privacy

Alle voortgang blijft op het eigen apparaat (localStorage).
Niets gaat naar internet — kind-veilig.
